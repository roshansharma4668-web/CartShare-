# CartShare - Collaborative Shopping Ecosystem

CartShare is a real-time collaborative shopping web application built to streamline group purchases in shared spaces (hostels, apartments, office teams). It eliminates duplicate orders, helps groups meet free shipping thresholds, and transparently logs who added each item.

## 🛠️ Features

- **Room System:** Create or join isolated rooms using unique codes.
- **Shared Real-Time Cart:** Add and remove items with instant synchronization across multiple browser tabs/windows without page reloads.
- **Free Delivery Tracker:** Visual progress bar tracking order value against a ₹500 minimum threshold.
- **Live Activity Log:** Real-time chronological audit trail of all member actions (joins, adds, deletes).
- **Printable Group Receipt:** Audit-ready, clean invoice generation formatted specifically for printing/saving as PDF using CSS print media queries.
- **Responsive Design:** Mobile-first layout fully styled with Bootstrap 5 and custom CSS.

## 💻 Tech Stack

- **HTML5:** Semantic markup and structured forms.
- **CSS3 & Bootstrap 5:** Responsive Grid, Flexbox, components, and `@media print` styling rules.
- **JavaScript (Vanilla JS):**
  - Application logic and DOM manipulation.
  - Browser `localStorage` for data persistence.
  - `storage` event listeners for cross-tab synchronization.
